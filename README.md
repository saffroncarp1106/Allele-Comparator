# Allele-Comparator
Used BioPython, this is just a quick script to output and compare two alleles. i am sure the code already exists somewhere, but here is  mine I had made a year ago.

To use:

use this cmd in windows

pip install biopython

Cd to your folder with all assets.

Run this command

python compare_alleles.py allele_A.fasta allele_B.fasta
